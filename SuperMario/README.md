# SUPER MARIO · 超级玛丽

一个纯 HTML5 Canvas 实现的网页版超级玛丽（马里奥）小游戏，零依赖、零构建，**双击 `index.html` 即可直接游玩**。

## 运行方式

1. 双击打开 `index.html`（本地 `file://` 协议即可，无需服务器）
2. 或用浏览器打开该文件

## 操作说明

| 按键 | 功能 |
|------|------|
| ← →（或 A / D） | 左右移动 |
| ↑ / W / 空格 | 跳跃（按住更高） |
| ↓（或 S） | 下蹲 |
| R | 重新开始 |
| P | 暂停 / 继续 |
| M | 静音 |

## 玩法

- 从左侧出发，向右前进，到达旗杆处即**通关**
- **踩**到敌人头顶即可消灭它（栗子头 / 乌龟）
- 收集金币加分
- 顶 `?` 问号块获得金币，顶砖块可得分
- 3 条命，掉坑或被敌人碰到会损失生命

## 项目结构

```
SuperMario/
├── index.html        # 入口页面（含 HUD 与样式）
└── js/
    ├── config.js     # 配置、图块定义、关卡地图、精灵数据
    ├── input.js      # 键盘输入处理
    ├── audio.js      # WebAudio 音效
    ├── renderer.js   # Canvas 渲染（地图/玩家/敌人/特效）
    └── game.js       # 游戏核心（物理、碰撞、敌人 AI、主循环）
```

## 技术要点

- **模块化设计**：按职责拆分多个 JS 文件，普通 `<script>` 加载，无需打包工具
- **像素风渲染**：`image-rendering: pixelated` + 纯色块绘制角色与场景
- **手感优化**：加入「土狼时间（Coyote Time）」与「跳跃缓冲（Jump Buffer）」让跳跃更顺滑
- **WebAudio 音效**：程序化合成音效，无需任何音频资源文件

## 扩展建议

- 在 `config.js` 的 `MAP_STR` 中编辑地图，`#` 地面、`B` 砖块、`?` 问号块、`|` 水管、`F` 旗杆
- 在 `ENEMY_SPAWNS` 中添加敌人（`goomba` / `koopa`）
- 增加道具（蘑菇变大、无敌星）可扩展 `bumpBlock` 逻辑
