# 游戏合集：中国象棋 & NEON BATTLE 2077 & 贪吃蛇 & 五子棋 & 超级玛丽

一个纯前端、零第三方依赖的小游戏仓库，包含五款风格各异的 Canvas 游戏：

| 游戏 | 目录 | 类型 | 技术栈 | 入口 |
| --- | --- | --- | --- | --- |
| 中国象棋 · 人机对战 | [`cn_chess/`](./cn_chess) | 棋类 / 人机 AI | 原生 JS、Canvas 2D、Web Audio | `cn_chess/index.html` |
| NEON BATTLE 2077 · 赛博坦克大战 | [`tank/`](./tank) | 俯视角射击 / 街机 | 原生 JS、Canvas 2D、Web Audio | `tank/index.html` |
| 贪吃蛇 Snake | [`snake/`](./snake) | 休闲 / 经典 | 原生 JS（ES Module）、Canvas 2D | `snake/index.html` |
| 五子棋 · 人机对战 | [`gomoku/`](./gomoku) | 棋类 / 人机 AI | 原生 JS（经典 script）、Canvas 2D | `gomoku/index.html` |
| SUPER MARIO · 超级玛丽 | [`SuperMario/`](./SuperMario) | 平台跳跃 / 经典街机 | 原生 JS（经典 script）、Canvas 2D、Web Audio | `SuperMario/index.html` |

所有游戏均不需要 `npm install` 或打包，直接用浏览器打开对应的 `index.html` 即可运行（贪吃蛇因使用 ES Module，建议通过本地服务器访问；五子棋与超级玛丽使用经典 `<script>` 加载，双击即可运行）。

## 快速开始

直接用浏览器打开对应页面即可：

- 中国象棋：双击 `cn_chess/index.html`
- 坦克大战：双击 `tank/index.html`
- 贪吃蛇：建议通过本地服务器访问（ES Module 在 `file://` 下受浏览器限制）
- 五子棋：双击 `gomoku/index.html`（经典 script 加载，无需服务器）
- 超级玛丽：双击 `SuperMario/index.html`（经典 script 加载，无需服务器）

```bash
# 贪吃蛇本地服务器
cd snake && python -m http.server 8000
# 访问 http://localhost:8000
```

推荐使用较新版本的 Chrome / Edge / Firefox。

## 游戏一：中国象棋 · 人机对战

经典 9×10 中国象棋棋盘，玩家与电脑 AI 对弈。

完整说明见 [`cn_chess/README.md`](./cn_chess/README.md)。

### 功能

- **难度选择**：简单 / 中等 / 困难，对应 AI 搜索深度 2 / 3 / 4。
- **先后手选择**：执红先手，或执黑后手。
- **完整规则**：马蹩腿、象塞眼、炮翻山、过河兵横走、九宫限制、飞将、将帅照面，以及“走后不能送将”的合法性校验。
- **人机对战**：AI 使用 negamax + alpha-beta 剪枝，配合子力分值、位置奖励和走法排序；同分最佳走法中随机选择，避免每局完全一样。
- **悔棋**：一次撤回“自己 + 电脑”的完整回合，并带棋子飞回动画。
- **认输 / 新游戏**：随时重开或结束当前对局。
- **棋谱面板**：记录每一手棋、吃子标记、每手用时和电脑搜索耗时。
- **交互与反馈**：点击选中、亮点提示合法落点、走子动画、吃子特效、将军冲击波与提示音。
- **合成音效**：走子、吃子、将军、悔棋均由 Web Audio 实时合成，无外部音频文件。

### 操作

| 操作 | 方式 |
| --- | --- |
| 选中棋子 | 点击己方棋子 |
| 落子 | 点击高亮落点 |
| 新游戏 / 悔棋 / 认输 | 页面上方按钮 |
| 切换难度 / 执子 | 页面上方下拉框（新游戏时生效） |

### AI 说明

- 评估函数：棋子基础分值（车 900、炮 450、马 400、象/士 200、兵 100、将 100000）+ 兵过河奖励 + 马的位置奖励。
- 搜索：负极大值搜索（negamax）+ alpha-beta 剪枝，难度对应深度 2～4。
- 终局：无合法走法即判定胜负；将死分值为 `MATE`。
- 搜索是同步执行的，电脑思考期间界面会短暂阻塞，属预期行为。

### 开发提示

- 在浏览器控制台可通过 `window.xiangqi` 访问对局控制器，例如 `xiangqi.undo()`。
- 根目录 `cn_chess/game.js` 仅供 Node 脚本 / 测试聚合导出，浏览器端不使用。

## 游戏二：NEON BATTLE 2077 · 赛博坦克大战

霓虹赛博风格的俯视角坦克射击游戏，支持单人和本地双人。

完整说明见 [`tank/README.md`](./tank/README.md)。

### 功能

- **单人 / 双人**：标题界面选择 `1 PLAYER` 或 `2 PLAYERS`，双人共用键盘。
- **关卡系统**：5 张 13×13 大格地图循环使用，每关 20 辆敌方坦克，场上同时最多 4 辆。
- **敌方兵种**：
  | 类型 | 特点 | 分值 |
  | --- | --- | --- |
  | `scout` | 常规侦察坦，速度慢、血量 1 | 100 |
  | `phantom` | 高速幻影坦 | 200 |
  | `striker` | 高射速、高弹速 | 300 |
  | `titan` | 4 点血量的重型坦 | 400 |
- **红色数据坦**：每关第 4 / 11 / 18 辆敌坦为红色，击毁后掉落道具。
- **六种道具**：
  | 道具 | 效果 |
  | --- | --- |
  | `overclock` | 火力升级，最高 3 级；满级可击穿钢墙 |
  | `emp` | 立即摧毁场上所有敌坦 |
  | `stasis` | 冻结敌人约 10 秒 |
  | `aegis` | 基地围墙临时变为钢墙 |
  | `nano` | 获得 600 帧护盾 |
  | `backup` | 增加 1 条备用生命 |
- **地形系统**：砖墙可逐格击毁；钢墙需满级火力；水域阻挡通行；冰面使坦克打滑；草丛在前景遮挡；主脑基地带砖墙保护。
- **基地机制**：前 10 关主脑基地免疫直接伤害，之后可被击毁；基地被毁即游戏结束。
- **战斗细节**：玩家与敌方子弹可相互抵消、同阵营子弹不抵消、敌方爆炸不震屏（玩家阵亡震屏）、粒子与数字碎片特效。
- **视效与音频**：霓虹辉光、CRT 扫描线、屏幕震动、Web Audio 合成音效与引擎声。
- **最高分**：启动时从 `localStorage` 读取（键名 `battlecity_hiscore`；当前版本未写回）。
- **自适应缩放**：根据窗口大小自动整数倍缩放画布。

### 操作

**单人**

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或方向键 |
| 射击 | `J` 或 `空格` |
| 暂停 | `P` |
| CRT 扫描线 | `C` |
| 辉光开关 | `G` |
| 静音 | `M` |

**双人**

| 玩家 | 移动 | 射击 |
| --- | --- | --- |
| P1（青蓝） | `W` `A` `S` `D` | `J` |
| P2（黄色） | 方向键 | `K` |

标题界面用方向键 / `W` `S` 切换选项，`Enter` 或鼠标点击开始；结算界面按 `Enter` 返回标题。

### 玩法提示

- 初始有 2 条备用生命，出生护盾持续期间免疫伤害；生命耗尽后该玩家退场。
- 摧毁全部 20 辆敌坦即过关，进入下一关。
- 满级火力是击穿钢墙的唯一方式。
- 冰面会保留滑行惯性；水域无法通过，但子弹可以飞越。

## 游戏三：贪吃蛇 Snake

经典贪吃蛇，深色赛博风格界面。

完整说明见 [`snake/README.md`](./snake/README.md)。

### 功能

- 蛇移动、吃食物、身体增长；撞墙 / 撞自身判死。
- 随机食物（避开蛇身生成）。
- 得分（每颗 +10），每 5 分自动加速，最快 60 ms/格。
- 最高分 `localStorage` 持久化（即时写回）。
- 暂停 / 继续 / 重新开始。
- 蛇头带眼睛，随移动方向朝向。
- ES Module 模块化，职责清晰分文件。

### 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `↑` `↓` `←` `→` 或 `W` `A` `S` `D` |
| 暂停 / 继续 / 重启 | `Space` 或 `Enter` |

### 状态机

```text
idle ──[方向键]──→ running ──[Space]──→ paused
                      │                    │
                  [死亡]       ◄──[Space]──┘
                      ↓
                    over ──[Space/Enter]──→ idle
```

## 游戏四：五子棋 · 人机对战

本地双人之外的“玩家对战电脑”模式五子棋，电脑 AI 完全在本地运行，无需联网。

完整说明见 [`gomoku/README.md`](./gomoku/README.md)。

### 功能

- **人机对战**：开始前可选执黑（先手）或执白（后手）；选白时电脑自动先手。
- **无禁手自由规则**：横、纵、两条斜线任意方向连 5 子及以上即胜，不实现禁手。
- **本地 AI（启发式）**：优先一步取胜 → 优先封堵玩家一步取胜 → 综合评估活四/冲四/活三/眠三/活二/眠二等棋形；空棋盘落中心，同分靠中。
- **交互**：最后一手标记、获胜连线高亮、鼠标悬停预览、电脑思考中禁止落子。
- **悔棋**：电脑思考中悔棋只撤玩家一手；电脑已回应则撤销电脑回应 + 玩家上一手；玩家执白时电脑开局首手保留；结束后也可悔棋。
- **AI 结果失效机制**：版本号 + 定时器清理，保证悔棋/重开后旧 AI 结果不再落子。
- **棋盘绝对居中**：信息栏不参与居中，固定于棋盘左侧；标题放大显示。

### 操作

| 操作 | 方式 |
| --- | --- |
| 开始游戏 | 选择执黑/执白后点击“开始游戏” |
| 落子 | 点击 / 触摸棋盘交叉点 |
| 悔棋 / 重新开始 | 侧边栏按钮 |

### AI 说明与局限

- 识别连续子构成的棋形；不识别带空档的“跳活三”（会低估为活二/眠二）。
- 一步成五的跳四由穷举扫描保证不漏；双活三等多点同时威胁按评分选最优应对。
- 不做多层搜索、不保证必胜，属启发式基本对弈水平。

### 测试

```bash
cd gomoku && node tests.js   # 规则与 AI 基础测试（49 项）
```

## 游戏五：SUPER MARIO · 超级玛丽

致敬经典的横版平台跳跃游戏，像素风渲染，零依赖、零构建，双击即玩。

完整说明见 [`SuperMario/README.md`](./SuperMario/README.md)。

### 功能

- **平台跳跃玩法**：从左侧出发向右前进，抵达旗杆处即通关。
- **两种敌人**：栗子头与乌龟，踩其头顶即可消灭；侧面或底部碰到则损失生命。
- **金币与砖块**：收集金币得分；顶 `?` 问号块获得金币，顶砖块得分。
- **生命机制**：3 条命，掉坑或被敌人碰到损失生命，生命耗尽游戏结束。
- **手感优化**：土狼时间（离开平台后 6 帧内仍可起跳）与跳跃缓冲（落地前 6 帧内按跳也生效）让操作更顺滑；按住跳跃键跳得更高。
- **像素风视效**：`image-rendering: pixelated` + 纯色块绘制角色与场景。
- **合成音效**：Web Audio 程序化合成，无任何音频资源文件。

### 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `←` `→` 或 `A` `D` |
| 跳跃（按住更高） | `↑` / `W` / `空格` |
| 下蹲 | `↓` 或 `S` |
| 重新开始 | `R` |
| 暂停 / 继续 | `P` |
| 静音 | `M` |

### 扩展提示

- 在 `js/config.js` 的 `MAP_STR` 中编辑关卡地图（`#` 地面、`B` 砖块、`?` 问号块、`|` 水管、`F` 旗杆）。
- 在 `ENEMY_SPAWNS` 中添加敌人出生点（`goomba` / `koopa`）。
- 道具（蘑菇变大、无敌星等）可通过扩展 `bumpBlock` 逻辑实现。

## 技术说明

| 项目 | 模块方式 | 命名空间 / 入口 | 持久化 | 调试入口 |
| --- | --- | --- | --- | --- |
| 中国象棋 | 普通 `<script>`（IIFE） | `window.XQ` | 无 | `window.xiangqi` |
| 坦克大战 | 普通 `<script>`（IIFE） | `window.NB` | localStorage 只读 | `window.__game` |
| 贪吃蛇 | ES Module | — | localStorage 读写 | `import { Game }` |
| 五子棋 | 普通 `<script>`（命名空间） | `window.Gomoku` | 无 | `window.Gomoku` |
| 超级玛丽 | 普通 `<script>`（经典顺序加载） | `window.Game` | 无 | `window.Game` |

- **渲染**：五款游戏均使用 Canvas 2D 绘制；坦克大战额外整数倍缩放适配窗口，超级玛丽使用像素风色块绘制角色与场景。
- **音频**：象棋、坦克大战与超级玛丽使用 Web Audio API 实时合成，不依赖任何音频文件；贪吃蛇、五子棋暂无音效。
- **逻辑 / 渲染分离**：贪吃蛇逻辑用 `setTimeout` 定频驱动，渲染用 `requestAnimationFrame` 独立运行；五子棋为回合制，仅在状态/悬停/尺寸变化时重绘。

## 兼容性

- 建议使用支持 Canvas 2D、Web Audio、ES6+、Pointer Events 的现代浏览器（Chrome / Edge / Firefox / Safari 较新版本）。
- 坦克大战、象棋与超级玛丽首次发声需要一次用户交互（浏览器自动播放策略）。
- 贪吃蛇使用 ES Module，需通过 HTTP 服务器访问（`file://` 在 Chrome 下会被 CORS 策略阻止）。
- 五子棋与超级玛丽使用经典 `<script>` 加载，可直接双击 `index.html` 运行，无需服务器。
